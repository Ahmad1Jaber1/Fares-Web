## 📝 How to Use This Website

### For Developers

1. **Quick Start**
   ```bash
   # Just open index.html in a browser
   # Or use a local server:
   python -m http.server 8000
   ```

2. **Customization**
   - Colors: Edit CSS variables in `css/style.css`
   - Content: Edit text in `index.html`
   - Images: Replace files in `images/` folder
   - Products: Add/edit product cards in HTML

3. **Deployment**
   - See SETUP_GUIDE.md for deployment instructions
   - See README.md for detailed documentation

### For Content Managers

1. **Update Products**
   - Open `index.html`
   - Find `<!-- Shop Section -->`
   - Edit product names, prices, and images

2. **Update Contact Info**
   - Open `index.html`
   - Find `<!-- Contact Section -->`
   - Update phone, email, and social links

3. **Change Images**
   - Replace images in `images/` folder
   - Keep the same filenames
